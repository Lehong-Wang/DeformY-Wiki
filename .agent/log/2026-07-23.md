## Papers & connections worth keeping (the map, not the pile)

Chosen direction first — **motion-manifold / latent-space planning**:

- **The manifold lineage** (one author line, Yonghyeon Lee): MMP → EMMP
  (CoRL'23, MIT code) → **MMP++** (T-RO'24, PyTorch code — the entry point)
  → DMMP (ICRA'26, dynamic throwing + kinodynamic constraints, code "coming
  soon") → OSMP (Hopf limit-cycle policies; the wind-up pillar, same
  author). Sibling: **DA-MMP** (2025, goal-conditioned flow-matching over a
  throwing-trajectory manifold, real 7-DoF ring-toss, no code). Recipe all
  of them share: offline trajectories (from trajopt) → learned
  differentiable manifold → latent generative model → optimize/condition on
  the manifold.
- **Latent-action adjacents**: QueST (VQ trajectory tokens, MIT), PRISE (BPE
  tokens — makes wind-up count a discrete searchable variable), Movement
  Primitive Diffusion (ProDMP backbone + deformable precedent, MIT),
  Diffusion-ES (manifold-preserving evolutionary search — the latent
  planner loop), PLAS (latent decoder as anti-exploitation trust region),
  D-Cubed (latent diffusion trajopt ON A ROPE — closest published match, no
  code), Lynch et al. Latent Plans from Play (the classic goal-encoder →
  latent → action-sequence-decoder topology).
- **Connection to the user's own sketch**: goal encoder + rope-physics
  encoder → joint latent → trajectory decoder ≈ DA-MMP + RMA-style context
  conditioning. Both halves are separately validated (DA-MMP; RMA/IIDA/
  RoboMorph); the composition is unclaimed. Mode-averaging is the trap —
  keep a small stochastic latent (CVAE/flow), goal+physics as conditioning.
- **Direction-conditioning precedents** (the task's hardest axis, nothing
  does it on a deformable tip): CNP-B (one-pass (position,
  velocity-direction) → B-spline decoder, real air hockey, TF — port the
  recipe), BMP (closed-form endpoint position+velocity pinning), table-
  tennis OCP terminal constraints.
- **Robust-planning spine** (now partly ingested in the wiki): PETS →
  RAZER (epistemic/aleatoric split CEM) → MOPO/MOReL (pessimism penalties)
  → DR-PETS (Wasserstein); funnel/reachability school (Funnel Libraries,
  DIRTREL, REFINE) = verified open-loop feasibility maps. Best env-native
  idea: posterior-batched robust search — tile the 10K parallel envs with
  rope-parameter posterior samples, CMA-ES on CVaR across them.
- **Task anchors** (for metrics/context, not direction): IRP (canonical
  task + single-correction escape hatch), DIDP (yardstick: 84.3%@5cm /
  20.8%@1cm sim), Bai SIMPAR'25 (SAC/PPO whip-targeting existence proof),
  Nah '23 (9-param min-jerk + black-box opt hits 3D whip targets — compact
  actions suffice). Flying Knots / Wiggle-and-Go: known-author systems,
  explicitly NOT the chosen direction (see .agent/DECISIONS.md 2026-07-23);
  at most harness/eval references.
