\section{Conclusion}
We proposed \methodname{}, a method for learning to perform real-world deformable object mobile manipulation tasks by inferring and adapting to the unknown dynamics of deformable objects in real-time. \methodname{} results from a two-phase training procedure that first infers a deformable object dynamics embedding from the object's recent ground-truth particle positions, and then infers this same embedding using recent robot visual observations and actions instead. \methodname{} achieved success in two deformable object mobile manipulation tasks across unknown deformable object dynamics, categories, and instances.
