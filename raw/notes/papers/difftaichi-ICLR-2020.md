# DiffTaichi — Differentiable Programming for Physical Simulation

**One-line gist**: Differentiable programming language and framework for physics simulation, with rope/mass-spring examples; widely used as a back-end for differentiable rope policies.

**Task setup**: Simulator/framework with built-in rope, mass-spring, MPM, and other examples.

**Sim vs real**: Sim only.

**Learning method**: None — framework.

**Action representation**: N/A.

**Why cited in the surveys**: Cited in Report 1 as a foundational differentiable-physics framework with rope/mass-spring support; underpins many downstream differentiable DLO research stacks.

**Key result (if any)**: First-class differentiable physics framework supporting rope, MPM, and rigid-body dynamics.
