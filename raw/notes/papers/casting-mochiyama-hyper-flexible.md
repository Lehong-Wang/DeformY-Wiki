# Casting and Winding Manipulation with Hyper-Flexible Manipulator

**One-line gist**: Hyper-flexible manipulator modeled as an underactuated multi-link with passive joints; explicit casting motion sends the tip of a flexible cable to a 3D target via inverse-dynamics planning of a single base actuator.

**Task setup**: A hyper-flexible manipulator casts and winds a flexible cable so that the tip reaches a 3D target.

**Sim vs real**: Demonstrated experimentally with sub-tip accuracy.

**Learning method**: None — inverse dynamics planning of a single base actuator on the underactuated multi-link model.

**Action representation**: Single base-actuator command profile (with the rest of the linkage passive).

**Why cited in the surveys**: Cited in Report 2 as one of the earliest goal-conditioned dynamic flexible-tip-targeting setups, predating modern learning-based work. Demonstrates that dynamic casting to a 3D target can be solved with classical inverse-dynamics planning on an underactuated structure.

**Key result (if any)**: Demonstrated casting and winding around remote targets with sub-tip accuracy.
