# High-Speed Batting Robot (Yamakawa-Senoo-Ishikawa)

**One-line gist**: Classical Univ. Tokyo high-speed batting robot — 1 kHz vision + high-speed arm hits a ball with near-perfect strike-zone accuracy. Non-learning dynamic hitting.

**Task setup**: Hitting an incoming ball with a high-speed robot arm + 1 kHz vision; near-perfect strike-zone accuracy.

**Sim vs real**: Real-world only.

**Learning method**: None — model-based control + 1 kHz visual servoing (Ishikawa lab style).

**Action representation**: Pre-planned, model-derived joint trajectories executed at 1 kHz with high-speed visual feedback.

**Why cited in the surveys**: Cited in Report 1 as the classical reference for non-learning dynamic hitting/striking — the "ceiling" of what 1 kHz vision + high-speed arm + model-based control can achieve. Pairs with the Yamakawa rope-knotting series as foundational classical work.

**Key result (if any)**: Near-perfect strike-zone hitting at 1 kHz visual feedback.
