# Throwing Objects into a Moving Basket While Avoiding Obstacles

**One-line gist**: RL in Gazebo (sim2real) for throwing rigid objects into a *moving* target basket while avoiding obstacles.

**Task setup**: Throw a rigid object into a moving basket while avoiding obstacles.

**Sim vs real**: Sim2real from Gazebo.

**Learning method**: Reinforcement learning.

**Action representation**: Throwing action conditioned on the moving target's position trajectory.

**Why cited in the surveys**: Cited in Report 1 as a goal-conditioned throwing variant with *moving* targets — useful as a methodological analog for tip-target reaching when the target itself is dynamic.

**Key result (if any)**: Sim2real throwing into moving baskets demonstrated.
